03 / highlights

Everything you do to a PDF, in one window.

The tools you reach for most, grouped the way you think about them, and none of it leaves your machine.

01

Organize pages

See your real pages. Drag to reorder, turn and delete, then apply it all in one pass.

02

Compress

Shrink a file, or fit a size limit like 2 MB. Handle whole folders at once.

03

Merge and split

Join files in the order you drag them. Break one into parts. Save everything in one click.

04

Sign

Draw, type or use an image, then drop it on the page and resize it.

05

Make searchable

OCR for scans, so you can search and copy the text.

06

Protect and clean

Passwords, hidden metadata, watermarks, page numbers, PDF/A, repair.

05 / for agents

Built for AI agents too.

Every tool is a command with predictable JSON output and stable exit codes. It never prompts, and it can run as an MCP server.

  • One JSON object per call, with named error codes an agent can act on.
  • The MCP server refuses to start without an explicit folder allow-list.
  • Passwords never travel on a command line.
# compress, then read the result as JSON
$ pdfsqueeze --json compress report.pdf --level recommended
{ "ok": true, "command": "compress", "result": { "saved_percent": 38.5 } }

# sign the last page
$ pdfsqueeze sign contract.pdf --image sig.png --page z

# let an assistant use it, limited to one folder
$ pdfsqueeze mcp --allow-dir ~/Documents/pdfs
06 / progress

Built in the open.

Here is what exists, and how well each part has been checked.

  1. 13 Oct 2026

    Organize, sign, and a calmer window

    One screen to reorder, turn and delete pages with real previews. Draw, type or use an image to sign. Merge with thumbnails and drag to reorder. One Save all for many results, a real progress bar, and a new look.

  2. 10 Oct 2026

    The app window and six downloads

    A real application window with drag-and-drop. Packages for macOS (Apple Silicon and Intel), Windows (64 and 32-bit) and Linux (x86_64 and arm64), each with its tools bundled.

  3. 09 Oct 2026

    The engine and the command line

    22 commands on top of Ghostscript, qpdf and Tesseract, a JSON mode, and an MCP server for AI agents.

Checked

  • Automated tests and an end-to-end test of every command on macOS, Windows and Linux.
  • Packages build and run in a clean environment with no other software installed.
  • Signature and page-edit placement measured against the output files, including rotated pages.

Not yet checked

  • The Windows window has not yet been used by a person on a Windows machine.
  • Dragging a file from Finder or Explorer onto the window.
  • Signing places a picture of your signature. Certificate-based digital signatures are not built.
