Private by design.

Most online PDF tools make you upload your file to their servers. pdfsqueeze does the work on your own computer, so contracts, IDs and scans stay where they are.

Nothing is uploaded

Files are processed locally. The app has no accounts, no analytics and makes no network requests for your documents.

Works offline

Everything you need is built in, so there is nothing else to install. Pull the plug and it still works.

Free and open source

Licensed AGPL-3.0, with the full source on GitHub. Built on the proven engines Ghostscript, qpdf and Tesseract.

One window for everything you do to a PDF.

Related tools sit together, so you are never hunting through menus.

CompressShrink a file, or fit a size limit like 2 MB. Batch whole folders.
Organize pagesSee your real pages. Drag to reorder, turn and delete, in one pass.
Merge and splitJoin files in the order you drag them, or break one into parts.
SignDraw, type or use an image, then place it on the page.
Make searchableAdd a text layer to scans with OCR, so you can search and copy.
ConvertPDF to images, images to PDF, and text extraction.
Protect and cleanAdd or remove a password, strip hidden metadata, inspect a file.
StampWatermarks and page numbers, in your own format.
Repair and checkRebuild damaged files and look for structural problems.
Archive as PDF/AConvert for long-term storage.
Fast web viewMake a PDF start showing before it has fully loaded.
Command lineEvery tool is also a command, with clean JSON output for scripts.

Built for AI agents too.

Every tool is a command with predictable JSON output and stable exit codes. It never prompts, and it can run as an MCP server so assistants can use it safely.

  • One JSON object per call, with named error codes an agent can act on.
  • The MCP server refuses to start without an explicit folder allow-list.
  • Passwords never travel on a command line.
# compress, then check the result as JSON
$ pdfsqueeze --json compress report.pdf --level recommended
{ "ok": true, "command": "compress", "result": { "saved_percent": 38.5 } }

# place a signature on the last page
$ pdfsqueeze sign contract.pdf --image sig.png --page z

# let an assistant use it, limited to one folder
$ pdfsqueeze mcp --allow-dir ~/Documents/pdfs

Progress, in the open.

This project is being built in public. Here is what exists, and how well each part has been checked.

  1. 13 October 2026

    Organize, sign, and a calmer window

    One screen to reorder, turn and delete pages with real previews. Draw, type or use an image to sign. Merge with thumbnails and drag to reorder. One Save all button for many results, a real progress bar, and a new light green look.

  2. 10 October 2026

    The app window and six downloads

    A real application window with drag-and-drop. Packages for macOS (Apple Silicon and Intel), Windows (64 and 32-bit) and Linux (x86_64 and arm64), each with its engines bundled.

  3. 9 October 2026

    The engine and the command line

    22 commands on top of Ghostscript, qpdf and Tesseract, plus a JSON mode and an MCP server for AI agents.

Checked

  • Automated tests and an end-to-end test of every command, on macOS, Windows and Linux.
  • All six packages build and run in a clean environment with no other software installed.
  • Placement of signatures and page edits measured against the output files, including rotated pages.

Not yet checked

  • The Windows window has not yet been used by a person on a Windows machine.
  • Dragging a file from Finder or Explorer onto the window.
  • Certificate-based digital signatures are not built; signing places a picture of your signature.
